# FEATHERFLOW — API Endpoint Catalog

Generated by introspecting the live Django URL resolver (code at HEAD + working tree, 2026-10-01) and each view's source. **335 application routes** (Django built-in `/admin/` ModelAdmin redirects, the media static route and the `/` redirect — 111 resolver entries — are excluded). Request-field, status-code, model, side-effect and pagination columns are **derived by static analysis of the view source** (regex over `request.data[...]`, `status=…`, referenced model classes, `.save()/.create()`, notification/audit helpers, `transaction.atomic`, `select_for_update/get_or_create`) — they are a reliable index but not a substitute for reading the view; blank = not detectable.

## Headline numbers

* Routes referenced literally from Flutter `lib/`: **105**; **230 have no literal Flutter reference** — most are admin/module routes built dynamically (`/api/admin-panel/<module>/…`), webhooks, health checks, or genuinely unused (see §Unused / duplicate).
* Routes whose path tail appears in a backend test script or `tests.py`: **185**; **150** have no textual test reference (heuristic).
* Live-called in this audit: **151 param-free GET routes × 19 identities (2,869 requests, 0 × 5xx)**, 76 object-level IDOR requests, plus workflow/seed/security probes. Remaining routes (parameterised, mutating) are exercised only by project scripts or the audit workflows named in the Live column.

## Cross-cutting facts

| Topic | Fact |
|---|---|
| Authentication | DRF default classes `VersionedJWTAuthentication` (SimpleJWT) **and `SessionAuthentication`** (so cookie-session callers — e.g. a logged-in Django-admin browser — are subject to the DRF CSRF check on unsafe methods); `PharmacyAlwaysOnAuthentication` on pharmacy routes that must work while pending/suspended; `/api/auth/login|register|verify|password-reset|registration-upload` are anonymous (throttled) |
| Authorization | per-role permission classes (`IsFarmerUser`, `IsDoctorUser`, `IsPharmacyUser`/`IsPharmacyAccount`, `IsDeliveryUser`, `IsResearcher…`, `IsFeedOwner…`, `IsAdminUser`) + `ModulePermission` (module/action from `roles.permissions`) + object ownership filters (`farmer=request.user`, `delivery_person=rider`, …) |
| Pagination | only admin collections (`limit/offset` → `{results,total,limit,offset}`) and a few lists; most farmer/pharmacy/community lists return everything (F-012) |
| Errors | uniform envelope `{"detail":…, "error":{"code","message","request_id"}}` (`api/exceptions.py`); throttle → 429 `THROTTLED` |
| Idempotency | subscription checkout via `idempotency_key`; delivery `delivered` retry is idempotent; feed stock decrement uses row locking; expense/revenue/post creation is **not** idempotent (F-039) |
| Audit logging | admin mutations call `_log(...)` → `activity_logs`; pharmacy actions log to the same table; farmer/doctor actions mostly do not |

## Unused / duplicate / suspicious routes

| Finding | Detail |
|---|---|
| Duplicate families | `/api/costs/*` (7) ≈ `/api/farmers/costs/*`; `/api/feed/*` (4) ≈ `/api/farmers/feed/*`; `/api/workers/*` (4) ≈ `/api/farmers/labor/*`; `/api/farmers/tax/payment/` ≈ `/payments/`; `/api/vets/nearby/` ≈ `/api/consultations/vets/nearby/`; `/api/doctors/updates/` ≈ `/api/doctor/updates/` — Flutter calls only the `/api/farmers/*` and `/api/consultations/*` variants |
| Legacy JSON-bridge | `/api/pharmacy/<kind>/` (+ `/<record_id>/`) with kind ∈ {products, orders}; `GET /api/pharmacy/*` handlers call `_seed()` (F-004) |
| Wrong status semantics | `GET /api/delivery/orders/<id>/route/` returns 404 for any Google failure (F-003) |
| 500 on bad input | `PATCH /api/admin-panel/<module>/<non-uuid>/` (F-025) |
| Over-broad read | `/api/pharmacy/marketplace/` returns `owner_id`/`pharmacy_user_id` to every authenticated role; `/api/farmers/pharmacies/` returns pharmacy e-mail/phone/licence (F-035) |
| Webhook | `POST /api/payments/webhook/<provider>/` — signature verification only exercised in dev mode |
| Flutter field mismatches | none observed in 24 browser sessions (no Flutter parse errors on 2xx responses); Flutter reads a subset of returned fields (e.g. login returns `user_url`, `next`, `documents` — only `user`, `access`, `refresh` used) |
